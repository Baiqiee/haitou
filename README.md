# 《海投》· 单文件增量放置游戏

一个关于找工作的增量（放置）游戏。玩家扮演求职者，唯一动作是**投递简历**；正向反馈带来「动力」，动力用来解锁软件功能；投递越多，世界越冷漠；最终也许能拿到一份 Offer——岗位是「简历筛选专员」。

## 在线试玩

打开仓库的 GitHub Pages 地址即可直接玩（单文件、零依赖，加载完就能玩）：

```
https://<用户名>.github.io/haitou/
```

本地运行：直接双击 `index.html`，或用任意浏览器打开即可。无需构建、无需联网、无需安装依赖。

## 玩法

1. 桌面上打开「海投直聘」→ 点中间那个巨大的【投递】（或按空格键）。
2. 每次投递会随机得到一条反馈：
   - 无动力：已读不回、感谢信、不合适、进入人才库、系统自动回复、岗位已下线、已投递过、HR 已离职。
   - 有动力：简历被查看 +1、HR 打招呼 +3、索要作品集 +5、约笔试 +8、一面被拒 +15、二面被拒 +25、终面被拒 +40、进入背调 +60。
3. 动力每小时衰减 10%，只用于解锁软件功能，不积攒就浪费。
4. 达成「投递 ≥ 50 万 / 正向反馈 ≥ 5000 / 被拒轮次 ≥ 100」后触发 Offer 事件链，任一环节被拒会退回，进度保留。

### 桌面上的软件

| 软件 | 作用 |
| --- | --- |
| 海投直聘 | 主界面：投递 + 反馈信息流 |
| 简历工厂 | 反馈质量线：提高正向反馈概率 |
| 电脑管家 | 投递速度线：自动投递；列表末尾有额外技能「AI 代投」（可单独解锁，让 AI 每隔一段时间替你投一份） |
| 被拒宝典 | 被拒推进线：提高深层被拒的出现率与事件链通过率 |
| 贪吃蛇.exe | 摸鱼小游戏。等 AI 代投的时候可以玩，破纪录会给一点点动力 |
| 邮件 | 收录《录用通知》 |
| 我的电脑 | 进度、事件链条件、存档与重置 |

### 设计上的几个点

- **荒诞机制**：投递数越多，正向反馈概率越低——越努力，世界越冷漠。
- **挂机友好**：AI 代投可以按 30 秒 / 1 分钟 / 5 分钟 / 15 分钟的节奏自动投递，适合长时间挂着。
- **即时反馈**：每次投递会在按钮上方弹出气泡、更新「最近反馈」条，任务栏数字会跳动。
- 窗口可拖动，任务栏可切换软件，进度自动存进 localStorage。

## 技术说明

- 单个 `index.html`，内含全部 HTML / CSS / SVG / JavaScript，**零依赖、零构建**。
- 场景是第一人称视角的扁平粗描边矢量插画（纯 SVG），屏幕内的「海投 OS」是 DOM 实现的窗口系统：可拖拽窗口、任务栏、桌面图标、通知气泡。
- 音效用 WebAudio 现场合成（投递「咔」、正向「叮」、被拒「叮——」、Offer 电话铃后突然安静），无音频文件。
- 存档键：`haitou_v2`（localStorage）。
- 贪吃蛇小游戏用 Canvas 绘制，24×16 格，方向键 / WASD 控制，空格暂停。
